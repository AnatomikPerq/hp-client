# Конфиденциальность

HYPER CLIENT не собирает и никуда не отправляет данные об использовании,
посещённых сайтах или трафике. В нём нет аналитики, телеметрии, рекламы и
аккаунтов.

## Какие запросы делает приложение

- **Подписки**, которые вы добавили: скачиваются по их адресам (только HTTPS).
  Если включить HWID для подписки, её серверу уходит заголовок с
  идентификатором устройства, только ему и только после вашего согласия.
- **GeoData** (`geoip.dat`, `geosite.dat` и другие, которые вы подключите):
  скачиваются с указанных для них адресов, по умолчанию с релизов GitHub.
- **Проверка обновлений:** запрос к GitHub API о последнем релизе
  [AnatomikPerq/hp-client](https://github.com/AnatomikPerq/hp-client).
  Ничего не скачивается и не запускается само: откроется страница релиза.
- **Пинг узлов** и **проверка живого подключения:** короткие запросы к
  адресу проверки (по умолчанию Cloudflare или Google) через проверяемый узел
  или текущее подключение. Для определения страны узла используется сервис
  геолокации по IP.
- **Трафик ваших подключений** идёт через серверы, которые вы указали.
  Клиент сам серверов не предоставляет.

## Что хранится на устройстве

Узлы, подписки, ключи age, настройки маршрутизации и журналы (если вы их
включили) хранятся только локально, в папке данных приложения. Резервная
копия, если вы её настроили, пишется одним файлом в выбранное вами место,
например в папку OneDrive. **Она не зашифрована** и содержит учётные данные
узлов и адреса подписок: храните её как пароль.

## Системный прокси

В режиме «Системный прокси» приложение запоминает прежние настройки прокси
Windows и возвращает их при отключении, при сбое ядра и при следующем
запуске после краша. Если за это время прокси поменяла другая программа, её
настройки остаются как есть.
